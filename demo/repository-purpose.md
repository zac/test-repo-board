# Repository purpose

This public repository contains synthetic tasks, plans, progress reports, and pull requests used to demonstrate [Repo Board](https://github.com/zac/webmcp-repo-board).

The corresponding [live board](https://webmcp-repo-board.zacwhite.workers.dev/boards/zac/test-repo-board) is safe to inspect without signing in. Its sample cards show how work moves through human planning, agent implementation, GitHub review, and completion.

No production source code, customer data, credentials, or private repository details belong here.
